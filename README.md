# Nomadik Sentinel Frontend

This repository contains the static frontend landing page and dashboard application for the Nomadik Security platform deployed via Cloudflare Pages.

## Overview

Nomadik Sentinel provides active-defense and compliance monitoring infrastructure. This frontend interface communicates with the backend services to display live telemetry, threat analytics, and system status updates.
